= Changelog

== 0.1.12 (2026-10-21)

* **Companion UI auto-injects on `uiLoaded`.** Partials (`nav-tree`), Handlebars helpers, CSS, and the SVG sprite merge into the UI catalog at build time (same pattern as `@antora-supplemental/site-nav-tree` and `@antora-supplemental/antora-search-chat`). Hubs no longer need to copy `ui/` into `supplemental-ui/`; stale copies are replaced when present. Disable with extension config `ui: false` or `injectUi: false`.

== 0.1.11 (2026-10-17)

* **Overview inherits a typed parent's icon.** An Overview leaf whose parent nav node carries a typology (Diátaxis bucket, spec component/feature, changelog) now renders that parent's icon in front of it. Its own typology stays `overview`, so bold landing-peer styling still applies; an Overview under an untyped or overview parent keeps no icon.

== 0.1.10 (2026-10-17)

* **Overview leaves carry no typology icon** and render **bold**, like Changelog items. The `overview` typology id (and `data-nav-typology="overview"`) is unchanged, so current-page styling and hard-sort still treat Overview/Home as landing peers.

== 0.1.9 (2026-10-17)

* Nav tree alignment: center typology icons with label text (drop extra `margin-top`); recalculate expander chevron `top` for the smaller `--nav-typology-toggle-size` so carets line up with the first text line (Valentus assumed 0.8em glyphs).

== 0.1.8 (2026-09-26)

* **Component-root icons off by default** (Home, Business Bootstrap, Platforms, …). Expanders already mark roots; icons were too noisy. Opt in with `site.keys.nav_typology_component_root_icons: 'true'`.
* **Solid glyph set** (filled SVG, not wireframe): Overview = square; Changelog = three short bars; Tutorials = graduation cap; How-to = work glove; Reference = book; Explanation = open encyclopedia/wiki book. Spec marks updated to match.
* Larger default icon size (`--nav-typology-icon-size: 1.05em`) and DeepWiki-like nav type scale (`0.875rem` items / `0.9375rem` depth-0 roots); expander toggle `0.625rem` (smaller than text).
* Drop `overflow-x: auto` on the tree (use `hidden` + wrapping labels) to avoid nested horizontal scrollports / wheel jank.

== 0.1.7 (2026-09-26)

* **Overview** typology icon for nav labels Overview/Home (forest start-page peers).
* Explicit typology from page attrs `:page-nav-typology:` / `:nav-typology:` (URL map at `navigationBuilt`).
* Config `diataxisUrlExcludePrefixes`: skip Diataxis *URL path* heuristics under listed prefixes (Business Bootstrap tree hierarchy); explicit attrs and `navTypologyId` still apply.


== 0.1.6 (2026-09-25)

* Diataxis inheritance: linked leaves inherit the parent typology unless their URL introduces a new recognized bucket (fixes cross-component How-to entries such as Bitwarden CLI / gcloud CLI under general-knowledge).
== 0.1.5 (2026-09-25)

* Hard-sort nav siblings **Home/Overview** then **Changelog/Activity Log** then the rest (extends the former changelog-only hoist).

== 0.1.4 (2026-09-01)

* UI helpers require `@antora-supplemental/nav-typology/lib/resolve-typology` (Antora `requireFromString` cannot load sibling helper modules).

== 0.1.3 (2026-09-01)

* Diátaxis detection: URL path wins over title prefix (fixes *Reference reliability* under `/explanation/`).
* Title heuristics apply only to unlinked nav headers (no URL).
* Unlinked section headers inherit the nearest ancestor Diátaxis typology at build time; render helpers accept `parentTypologyId` from `nav-tree`.
* Nav CSS: top-align typology icons (`flex-start`); single-line labels with horizontal scroll on deep trees.

== 0.1.2 (2026-09-01)

* Changelog typology icon (`icon-changelog`) with warm accent + semibold label.
* Auto-detect `changelog` / `activity-log` nav entries; hoist them to second slot in each branch.
